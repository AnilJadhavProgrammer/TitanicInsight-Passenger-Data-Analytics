# TitanicInsight — Passenger Data Analytics

TitanicInsight is a **data analytics and exploratory data analysis (EDA) project** focused on understanding passenger information from the Titanic dataset.

The project performs data cleaning, exploratory analysis, and visualization to identify relationships, patterns, and trends across passenger attributes such as survival status, passenger class, age, and gender.

## Overview

The objective of this project is to explore the Titanic dataset and understand the factors and relationships present within the passenger data.

The analysis includes:

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Univariate analysis
* Relationship analysis between variables
* Data visualization
* Identification of patterns and trends
* Interpretation of analytical findings

## Dataset

The project uses the **Titanic dataset**, which contains information about passengers who traveled on the Titanic.

Key attributes include:

* Passenger survival status
* Passenger class
* Age
* Gender
* Passenger details
* Other passenger-related attributes

Dataset source: [Kaggle](https://www.kaggle.com/code/vbmokin/eda-for-tabular-data-advanced-techniques)

## Analysis Performed

### Data Cleaning

The dataset is examined and prepared for analysis by identifying and handling data-quality issues.

### Exploratory Data Analysis

EDA is performed to understand the distribution of passenger attributes and identify important patterns within the dataset.

Relationships between different variables are explored to understand how passenger characteristics are associated with survival and other outcomes.

## Installation

Make sure Python is installed on your system.

Install the required libraries:

```bash
pip install pandas matplotlib seaborn
```

For Jupyter Notebook:

```bash
pip install notebook
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/AnilJadhavProgrammer/Titanic-Dataset-Exploratory-Data-Analysis.git
```

Navigate to the project directory:

```bash
cd Titanic-Dataset-Exploratory-Data-Analysis
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```text
titanic_eda.ipynb
```

Run the notebook cells to perform the complete analysis.
